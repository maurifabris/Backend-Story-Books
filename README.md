# Backend Story Books

A personal project built to learn and demonstrate full-stack development skills using Node.js, Express, MongoDB, and Google OAuth authentication. Based on a YouTube tutorial and customized for learning purposes and portfolio building.

## 🚀 Tech Stack

- **Node.js** – Backend runtime environment
- **Express** – Web framework
- **MongoDB & Mongoose** – NoSQL database and ORM
- **Handlebars** – Templating engine for server-side rendering
- **Passport.js (Google OAuth 2.0)** – Authentication
- **dotenv** – Environment variable management
- **Method-Override** – HTTP verb override support (for PUT/DELETE)
- **Session & Flash Messages** – Express-session and connect-flash for auth flows

## 📚 About

This project allows users to authenticate with Google, create public or private stories, and view stories from other users depending on visibility settings. It was built following a YouTube tutorials, with modifications and improvements to better understand key backend concepts and architecture.
